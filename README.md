# Poroteo Legislativo

Herramienta abierta para analizar votaciones nominales de la Cámara de Diputados de la Nación Argentina (HCDN) y estimar "poroteos" legislativos a partir de datos públicos.

El proyecto procesa los registros de votaciones nominales publicados por la HCDN para explorar patrones de comportamiento de bloques y legisladores, y proyectar el resultado probable de una votación en función de posiciones históricas. La app final se publica en Streamlit.

## Estado

Proyecto en etapa inicial.

## Fuente de datos

Los datos utilizados provienen de fuentes públicas de la Honorable Cámara de Diputados de la Nación (HCDN). Los archivos de datos crudos no se versionan en este repositorio.
